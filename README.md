# TERMINAL — симулятор пробития брони

Игра-симулятор терминальной баллистики: 2D-разрез брони, частицы, физически честные числа.
Решатель — явный 2D MLS-MPM на WebGPU (compute-шейдеры WGSL), одна кодовая база для ПК и Android.

Спека: [ARMOR_SPEC v0.1 в Claude Docs](https://claude.ai/artifact/XTpFrjDVeTQ7sCFfkSQdRt) — источник правды по физике,
числам и вехам. В репо лежит её выгрузка в Markdown: [`docs/ARMOR_SPEC.md`](docs/ARMOR_SPEC.md).

## Статус: веха M1 — ядро металлов

Что сделано, результаты гейта и открытые вопросы: [`docs/M1.md`](docs/M1.md); веха M0 — [`docs/M0.md`](docs/M0.md).

- **Ядро M1**: Ми–Грюнайзен, Джонсон–Кук (прочность и разрушение), откол, искусственная вязкость, контакт двух
  полей, осесимметричный режим. P2G на i32-атомиках с фиксированной точкой — побитовый детерминизм (4.6).
- **Гейт M1** (12.1, 12.2, 12.5, 12.7, 12.10): на CPU-эталоне в CI, на GPU в e2e и на устройстве — вкладка
  «Валидация».
- **Демо**: цилиндр Тейлора (медь, 190 м/с) и упругий блок M0; поля скорости, давления, температуры,
  пластической деформации, повреждения, напряжения по Мизесу.
- **Бенчмарк** «частиц × шагов в секунду» по пресетам 2.1 и **самопроверка** ядра (GPU против CPU-эталона
  во float64, режимы хранения «Полный» и «L2») + JSON-отчёт.
- **Android**: Capacitor-проект в `android/`, CI собирает debug-APK.

## Запуск

Готовая сборка: **https://4udofruct1k.github.io/6prac/** — обновляется при каждом пуше в `main` и в рабочую ветку
(workflow `Pages`). Нужен браузер с WebGPU.

Локально:

```bash
npm ci
npm run dev          # http://localhost:5173 — нужен браузер с WebGPU (Chrome/Edge 113+, на Android — Chrome 121+)
```

Параметры адреса: `?tab=gate` — сразу гейт M1, `?tab=bench` — бенчмарк, `?tab=device` — устройство и самопроверка,
`?compat` — принудительный режим совместимости WebGPU (как на старых Android с OpenGL ES 3.1).

## Тесты

```bash
npm run typecheck
npm test             # юнит-тесты и CPU-эталон (vitest, без GPU), секунды
npm run test:gate    # гейт вехи (раздел 12) на CPU-эталоне, ~2 мин
npm run test:e2e     # WGSL-ядра, гейт на GPU и рендер в Chromium на SwiftShader (Playwright)
```

Перед первым e2e: `npx playwright install chromium`. Браузер открывается в окне (в headless WebGPU-canvas
не работает); без дисплея — `xvfb-run -a npm run test:e2e`.

## Телефон

1. Скачать `terminal-debug-apk` из артефактов последнего прогона CI (вкладка Actions) и установить.
   Или собрать локально: `npm run android:sync && npm run android:open` → Run в Android Studio (JDK 21).
2. В приложении: «Валидация» → пресет «Телефон» → «Запустить гейт»; при желании «Устройство» → «Самопроверка
   ядра» и «Бенчмарк»; затем «Отчёт» → «Скопировать JSON».
3. На ПК то же в браузере с пресетом «ПК-Высокий» — по этому отчёту закрывается гейт M1 на реальном GPU.

Отладка WebView: `chrome://inspect` на ПК (в debug-сборке включено `webContentsDebuggingEnabled`).

## Структура

Модули по разделу 13 спеки; созданы те, что нужны M0 и M1.

| Папка | Что внутри |
| --- | --- |
| `src/sim/` | Ядро MPM: WGSL (`kernels.ts`), хост WebGPU (`GpuMpm.ts`), раскладка буферов, баланс энергии, самопроверка |
| `src/cpu-ref/` | Тот же алгоритм на TypeScript в float64 (`CpuMpm.ts`, модель материала — `physics.ts`) |
| `src/materials/` | База материалов (JSON по 7.6, zod), источники, модели EOS и JC |
| `src/scene/` | Пресеты качества, засев частиц, сцены демо, бенчмарка и цилиндра Тейлора |
| `src/validation/` | Сценарии раздела 12, метрики, раннер гейта на CPU или GPU |
| `src/render/` | Рендер частиц сплэтами из буфера ядра |
| `src/bench/` | Бенчмарк M0 |
| `src/ui/` | Preact-интерфейс |
| `tests/` | Юнит-тесты (vitest); `tests/gate/` — гейт вехи на CPU-эталоне |
| `e2e/` | Headless-прогоны ядра и интерфейса (Playwright) |
| `android/` | Capacitor-обёртка |
